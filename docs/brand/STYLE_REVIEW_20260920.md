# SK 界面样式统一检查 · 2026-09-20

本次处理公开版的视觉不一致，延续 SK 图标与系统字体。修改仅保存在本地；GitHub 源码上传仍暂停。

## 发现与修改

| 区域 | 原有差异 | 本次处理 |
|---|---|---|
| 全局主题 | SK 深绿、黑色主按钮、蓝紫色强调、米黄背景并存 | 新增统一主题层，兼容既有两套变量及 Arco 主色 |
| 主操作 | 普通页面、弹窗与抽屉规则不同，暗色悬停仍为黑色 | 统一默认、悬停、禁用、键盘焦点与 8px 控件圆角 |
| 状态标签 | 暗色背景继承旧紫色，部分文字对比不足 | 状态前景／背景随主题变化；保留成功、警告、失败、信息的含义 |
| AI 工作台 | 白底、奶油渐变、蓝色按钮和不同字体混用 | 对话、概要、蓝图、讲解、审核、差异、引用、验证等组件接入共享样式 |
| AI 消息 | 正文整体过粗；部分气泡内部内容假定永远是白字 | 正文字重恢复常规；气泡、引用、链接与表格适应主题 |
| 登录与项目 | 登录辅助区域蓝渐变；项目页黑粉色主视觉、米黄卡片 | 统一品牌色、背景、边框和文字层级 |
| 知识与连接 | 局部单独指定字体栈 | 统一系统字体变量，代码保持等宽字体 |
| 样式检查脚本 | 日期固定，结论包含不随扫描变化的“完成”描述 | 日期及输出文件名按运行日生成；明确源代码扫描不等于视觉验收 |

- Web 类型检查和生产构建通过。

- 弹窗输入后可通过 Tab 移至底部操作；控件有可见焦点。弹窗与抽屉可以正常关闭。
- 390px 窄屏检查：示例页面单列排列，没有页面横向溢出。该检查不代表所有业务页面均完成移动端适配。
- 生产登录入口重新加载验证品牌与共享样式；没有登录真实业务账号或提交业务操作。
- `git diff --check`、公开分发检查与本地 Git 历史密钥扫描无发现。

可复查入口：在 `web/` 运行开发服务器，访问 `/style-preview.html`。页面使用合成示例，所有输入停留在预览内存，不连接后端或付费模型。

## 源代码扫描与剩余范围

扫描覆盖 121 个页面和 129 个组件。存在硬编码十六进制颜色的文件由 57 减至 51。这只是发现线索：品牌源色、差异标记、图表分类与用户自定义报告均可能合理使用固定色，不能据此判断缺陷数量。

- `LearningFlow.vue` 等复杂流程图仍有大量节点、连线与交互颜色；应结合真实流程逐项核对，不能一律替换成品牌绿。
- `ReportDetail.vue` 中用户自定义报告配色属于内容配置，保留其原始含义。
- 其他低频管理页面以及权限、错误、长内容组合尚未逐页完成视觉验收。本次实际浏览器验证只覆盖上列入口和组件，不宣称全部 121 个页面已验收。
- 没有修改后台权限、审核状态机、调度或模型逻辑；全量后端既有失败项仍见[发布检查](../public/RELEASE_CHECK_20260920.md)。

回滚本次外观改造可在本地撤销对应样式提交，不需要迁移或回滚业务数据库。
