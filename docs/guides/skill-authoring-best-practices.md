## 📘 [核心原则](skill-authoring/core.md)

架构设计 / 决策树 / 参数 / 输出 — 设计一个 Skill 前先读这份。

- Skill 架构设计原则（粒度 / 结构分层 / description 写法 / 风险等级 / 目录结构）
- 决策树 5 大模式（阶梯 / 阶段 / 边界 / 兜底 / 冲突）+ 5 条铁律
- 参数设计规范（命名 / 默认值 / 影响表 / 避免 magic number）
- 输出定义四列含义 + 四大原则 + 输出契约

## 🧪 [测试与质量](skill-authoring/testing.md)

测试用例 / 反例 / 健康评分 / 常见错误 / 持续优化 — 要发布 Skill 前读这份。

- 5 类必测场景（正常 / 边界 / 缺失 / 极端 / 反例）
- 反例的 3 个来源 + 编写模板
- 健康评分 5 维（采纳率 / 成功率 / 覆盖 / 新鲜度 / 数据健康）+ 发布就绪检查
- 10 大常见错误（决策逻辑 / 测试 / 参数 / 架构）
- 持续优化方法论（PDCA / 日志分析 / 参数调优 / 漂移检测 / 生命周期）

## 🏭 [行业模板](skill-authoring/templates.md)

电商 / 客服 / 营销 / 财务 的 4 份完整 Skill 模板 + SKILL.md 格式参考。

- 电商：投放 ROI 评估
- 客服：服务质量监控
- 营销：内容效果分析
- 财务：文档结构化抽取
- 附录：SKILL.md 完整 frontmatter + 结构参考
- 附录：内置质量工具速查 + Lint 规则速查

## 快速起步

1. 读 **核心原则** 理解 Skill 的六层结构和决策树设计
2. 从 **行业模板** 复制一份最接近你场景的模板
3. 按模板填写业务逻辑
4. 用 **测试与质量** 里的自查清单校验
