# 公开准备版文档复核

[English](DOCUMENTATION_REVIEW.en.md) · 日期：2026-09-20

## 结论

项目文档原先混用了产品目标、历史实现记录和当前验收结果；部分操作步骤仍按旧部署环境描述。本次按当前代码修正入口和操作说明，不把文档更新当作功能接入或生产验收。

扫描起点为 Git 跟踪的 97 份 Markdown，包含介绍、设计、指南、示例和运行提示词。重点逐项核对 README、创建向导、编程运行时、Project SDK、训练出口及 Bridge 的实际调用路径。

## 文档无法替代的后续工作

1. **编程 Harness 尚未接入。** OpenCode 与 DeepSeek Harness 为候选；文档不能令已移除的执行路径恢复。
2. **模型节点与样本出口仍有历史耦合。** Project 服务保留 `236` 路由、`inference-primary` 别名及训练出口旧目标回退。出口在没有覆盖时默认启用，自动训练开关关闭并不关闭 trace 或样本记录；指南已如实说明，运行逻辑未在本次变更。
3. **部分运行提示词包含原使用者偏好。** 例如编程工作台提示词仍写“用户已明确表示 token 不怕浪费”。它属于行为配置，后续应改为明确的预算与质量策略并回归；本次未把运行提示词作为介绍文案批量修改。当前旧编程运行时仍不可用。
4. **授权、外部集成与业务收益需独立证明。** 第三方运行时 MIT 许可不替代本项目权属确认；代码、样例或测试通过也不能证明真实模型质量、员工覆盖率或商业收益。

这些限制保留在公开文档中；未改变 API、业务默认值、节点服务、模型配置或真实企业数据。
