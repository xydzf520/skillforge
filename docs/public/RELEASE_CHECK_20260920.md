## 本轮处理

- 中文与英文 README 加入开源生态定位，引用相关项目官方仓库；明确比较的是产品方向，不宣称首创、唯一或已完成集成。
- 将业务模板、界面及测试中的原业务品牌和部门上下文泛化为合成示例；重新建立仅包含最终清理内容的公开 Git 历史。此前准备过程的 Git 历史只在私有审计目录保留。
- 升级存在已知漏洞的 Python、Web 与流程编辑器依赖。固定 npm 11.13.0；保留兼容的 Monaco / Arco / vue-tsc 版本，对 Monaco 使用同一 3.4 系列已修复的 DOMPurify 覆盖，并更新锁文件。
- 补齐运行路径中缺少的 logger / json / 类型导入；修复公开版更新日志格式，使 API 能读取准备版记录。
- 被排除的私有 briefing 地址明确返回 404，不再被 SPA 首页掩盖。未随公开版分发的评论采集适配器明确报不可用，不阻止无关 MCP 工具和目录加载；未复制原部署脚本或凭据。
- 修正测试中的独立数据库、模拟在线节点和配置 fixture；没有为通过测试解除生产权限或开启训练自动化。
- 进一步删除原私有 AI 门户的整套对接代码：票据签发／核验、OIDC 提供方、签名密钥生成、身份转发、部署配置，以及桌面与移动导航入口。正常平台登录保留；未知 API 不再回退为网页首页。
