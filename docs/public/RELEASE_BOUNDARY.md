# 公开发布边界

公开源码仓库：[xydzf520/skillforge](https://github.com/xydzf520/skillforge)。当前发布清理后的公开预览源码、SK 品牌界面、中英文文档和独立部署配置。源码发布不代表全量回归、外部集成或生产部署已经验收；具体结果见[发布复核](RELEASE_CHECK_20260920.md)。

## 已处理

- 新建 Git 仓库，不继承原始提交、远程地址、作者邮箱或历史对象。
- 移除企业人员清单、运行数据、内部报告、截图、部署原件及真实运行结果。
- 内部域名、地址、用户名和个人路径替换为保留示例域名、通用名称或配置项。
- 原私有 AI 门户的专用单点登录、OIDC 提供方、身份转发和前端入口已从代码中删除，相关配置一并移除。公开版保留平台自身的账号密码和钉钉登录。
- 合成测试中的密钥外形字符串用于验证脱敏与拒绝，逐行注明用途，不是可用凭据。
- `.env`、密钥、数据库、日志、HAR、业务技能和第三方运行时不进入版本管理。
- 旧编程助手运行时已移除；自动训练部署、连续素材创建及平台后端自动注册系统服务默认关闭。Bridge 是独立安装程序，无参数运行仍会尝试安装服务，首次检查请显式使用 `--daemon`，见 [Bridge 说明](../../bridge/README.md)。
- 本地初始化生成独立随机凭据，不提供通用管理员密码。
