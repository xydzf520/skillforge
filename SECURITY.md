# 安全报告 Security policy

当前版本为公开预览，完整后端回归与生产部署尚未验收。维护重点为 `main` 上的当前公开代码，暂不承诺历史版本维护周期、响应时限或生产级安全保障。部署前请阅读[验证记录](docs/public/RELEASE_CHECK_20260920.md)。

请通过本仓库 **Security → Report a vulnerability** 私下报告漏洞：[私密报告入口](https://github.com/xydzf520/skillforge/security/advisories/new)。提供受影响版本、合成数据下的复现步骤、影响范围和建议修复方式；不要附带真实凭据、客户数据或生产数据库。

普通功能问题使用公开 Issue；漏洞细节、有效利用代码和敏感日志不要放在公开 Issue 或 PR 中。若私密入口暂不可用，请先联系[维护者](https://github.com/xydzf520)确认私密沟通方式，不要公开敏感材料。

## English

This is a public preview, with full backend regression and production acceptance still incomplete. Maintenance focuses on current public code on `main`; no response SLA, historical support window or production security guarantee is offered.

Use **Security → Report a vulnerability** to [report privately](https://github.com/xydzf520/skillforge/security/advisories/new). Include the affected revision, synthetic reproduction, impact and a suggested fix. Exclude live credentials, customer data and production databases. Do not disclose exploit details in public issues or pull requests. If private reporting is unavailable, contact the [maintainer](https://github.com/xydzf520) to arrange a private channel first.
